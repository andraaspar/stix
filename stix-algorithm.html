1. Binary Layout & Dual-Bitmap Architecture

The file STIX+5 /REM on Stix.d64 is packed with two sequential decrunchers (starting at $080B and $0801), followed by a crack intro at $0C40 and a 5-option trainer at $22C8. The trainer jumps to $7600, which initializes memory and enters the main game engine at $6000.

  • Graphics Mode: C64 Multicolor Bitmap Mode (160 × 200 logical pixels, 4 pixels per byte at 2 bits per pixel).
  • Visible Bitmap ($2000–$3FFF): Rendered by the VIC-II chip. Row base addresses are looked up via the table at $6F1B.
  • Shadow Bitmap ($A000–$BFFF): Accessed by setting bit 7 of the bitmap pointer high byte (LDA $46; ORA #$80; STA $46 at $697F). It stores 2-bit collision tags so visual colors and collision states stay decoupled.
Pixel State Visible Bitmap ($2000) Shadow Bitmap ($A000) Bitmask Table Used (X = x & 3)
Empty Space 00 00 Cleared with AND $75D9,X ($3F, $CF, $F3, $FC)
Stix Trail Segment 01 01 Set with ORA $757D,X ($40, $10, $04, $01)
Active Player Trail (Incomplete) 11 10 Visible: $75D1,X (11); Shadow: $7579,X ($80, $20, $08, $02)
Completed Boundary / Wall 11 11 Set with ORA $75D1,X ($C0, $30, $0C, $03)
Captured / Flood-Filled Area 10 (fast) or 01 (slow) 00 Visible set with $7579,X or $757D,X; Shadow cleared to 00

Why clearing the Shadow Bitmap on flood-fill matters: When erasing the oldest Stix segment (8 ticks later), routine $6928 checks if Shadow == 01. If the player captured that region in the meantime, Shadow was cleared to 00 during flood-fill, preventing the Stix's tail eraser from punching holes in newly captured territory.

3. Detailed Stix Movement Algorithm ($6703)

Every Stix update calls JSR $6703. Unlike arcade Qix (which reflects velocity vectors off walls), Supersoft's Stix uses two alternating behaviors driven by random bytes from $D41B:

3.1. Mode 0: Independent Endpoint Random Walk ($6781–$6801)

When $4B24 == 0 and the random roll $D41B < $F0 (93.75% probability), the engine updates the 4 endpoint coordinates (X1, X2, Y1, Y2) stored at $4B12..$4B15 one coordinate at a time in reverse order (index = 3, 2, 1, 0 → Y2, Y1, X2, X1):

  1. Read a random byte R = $D41B (stored in $4B19).
  2. Compute the number of 1-pixel sub-steps: steps = (R & 7) + 1 (between 1 and 8 pixels).
  3. Determine the sign from bit 7 of R:
    • If R < 128 (bit 7 = 0): step direction is +1. Upper limit is $75E1,X (155 for X, 195 for Y; must stay strictly less than this value, i.e., ≤ 154 for X and ≤ 194 for Y).
    • If R ≥ 128 (bit 7 = 1): step direction is -1. Lower limit is $75DD,X (≥ 4 for X, ≥ 17 for Y).
  4. For each 1-pixel increment/decrement of coordinate index:
    • Identify which endpoint was modified via ep = index & 1 (Endpoint 1 (X1, Y1) for index = 0, 2; Endpoint 2 (X2, Y2) for index = 1, 3).
    • Inspect the pixel at (X_ep, Y_ep):
      • If Visible == 00 (empty) or Shadow == 01 (Stix's own trail): allow step and continue the sub-step loop.
      • If Shadow == 10 (player's incomplete force field): set $4B42 = 1 (lethal collision flag) and continue.
      • Otherwise (hit a completed wall Shadow == 11 or captured territory Visible != 00, Shadow == 00): revert the 1-pixel step and immediately break out of the sub-step loop for this coordinate.

3.2. Mode 1: Targeted Swoop / Converging Charge ($670D–$6778 & $6804–$6861)

When $4B24 == 0 and $D41B ≥ $F0 (6.25% probability), the Stix initiates a high-speed swoop toward a single random point (TX, TY):

  1. Select random target (TX, TY):
    • Read Rx = $D41B. If Rx ≥ 152 ($98), abort Mode 1 and fall back to Mode 0. Otherwise TX = Rx + 4 (range 4..155).
    • Read Ry = $D41B ^ frameCounter ($4B25). If Ry ≥ 179 ($B3), abort Mode 1 and fall back to Mode 0. Otherwise TY = Ry + 17 (range 17..195).
  2. Precompute converging Bresenham trajectories ($698B & $69CB):
    • Generates a Bresenham line from (TX, TY) to (X1, Y1) in $4000 / $4200, then reverses the array in-place so index 0 is (X1, Y1) and the end is (TX, TY).
    • Generates a Bresenham line from (TX, TY) to (X2, Y2) in $4100 / $4300, then reverses it in-place so index 0 is (X2, Y2) and the end is (TX, TY).
    • Sets swoopIndex = 0 ($4B28) and picks swoopSpeed = $D41B & 6 ($4B27 → 0, 2, 4, or 6 steps per tick).
    • Triggers the SID Voice 1 pulse-width swoop sound effect ($6A7C).
  3. Step along trajectories on subsequent ticks ($6804–$6861):
    • In a loop of swoopSpeed iterations, increments swoopIndex and checks if either trajectory reached its 0 terminator or if (swoopPath1X[idx], swoopPath1Y[idx]) hits a wall or filled region.
    • If blocked or finished, clears $4B24 = 0, silences SID Voice 1, and jumps back to $6703 (Mode 0).
    • Otherwise, sets (X1, Y1) and (X2, Y2) from the trajectory arrays at swoopIndex. Because both paths converge on (TX, TY), the Stix visually shrinks as it accelerates across the playfield.

4. Line Rasterization, Wall Clipping & Endpoint Snapping ($6862–$6927)

After updating (X1, Y1) and (X2, Y2) via Mode 0 or Mode 1, routine $6862 rasterizes the line segment and enforces wall containment:

  1. Bresenham Rasterization (JSR $6D8B with $4B0D = 2): Computes every pixel along the segment from (X1, Y1) to (X2, Y2) and writes the coordinates into scratch buffers $4600 (X) and $4700 (Y), terminated by 0.
  2. Erase Oldest Trail Segment (JSR $6928): Reads slot k = $4B16 from $C000+k*$100 and $C800+k*$100. For every pixel in that slot, if Shadow(x, y) == 01, both Visible(x, y) and Shadow(x, y) are cleared to 00.
  3. Plot & Clip Loop ($688D–$68F5): Walks index X = 0, 1, ... through the candidate line buffer ($4600, $4700):
    • Empty pixel (Visible == 00): Sets Visible = 01 and Shadow = 01, and appends (x, y) to the current history slot at write index Y ($4B19).
    • Existing Stix pixel (Shadow == 01): Skips without modifying or recording in the new slot, and continues walking the line.
    • Player's incomplete trail (Shadow == 10): Sets player death flag $4B2B = 1 and continues walking the line.
    • Wall or Filled territory (Shadow == 11 or Shadow == 00, Visible != 00): Immediately aborts the loop (JMP $68F7), clipping the line segment right before the obstacle.
  4. Self-Shortening Endpoint Snap ($68F7–$6914):
    • If at least 2 pixels were drawn into the current history slot (Y ≥ 2):
      • (X1, Y1) is overwritten with the first drawn pixel in the slot (slot[0]).
      • (X2, Y2) is overwritten with the last drawn pixel in the slot (slot[Y - 1]).
    • Crucial consequence: If the Stix swings across a wall corner so that its midpoint hits the wall even though (X2, Y2) was in open space on the other side, clipping truncates the rasterized line at the wall and snaps (X2, Y2) back to the wall's edge. This prevents the Stix from ever jumping over walls or escaping its enclosure.

5. Screen-Splitting & Flood-Fill Algorithm ($6577 & $646E)

When the player completes a force field, the game does not flood-fill both sides to compare their areas. Instead, it uses a single-pass Wall-Following Exterior Normal Search ($6577):

  1. Starting at the Stix's first endpoint (X1, Y1), march right (INC $57) until hitting a wall pixel (Shadow == 11). Record this wall pixel as (startX, startY) at ($4B33, $4B34).
  2. Because the ray started at the Stix and went right (+X), the Stix's interior is on the left (-X) of this wall, and the exterior of the Stix's enclosure is on the right (+X).
  3. Trace clockwise around the inner perimeter of the Stix's enclosing wall using 4 directional states:
    • Moving Up ($6597): Exterior normal is Right (+X).
    • Moving Right ($65BC): Exterior normal is Down (+Y).
    • Moving Down ($65E1): Exterior normal is Left (-X).
    • Moving Left ($6606): Exterior normal is Up (-Y).
  4. At each boundary pixel along the walk, peek 1 pixel in the exterior normal direction:
    • Along the outer frame or previously captured walls, that exterior pixel is already non-zero in the Visible bitmap.
    • Along the newly drawn 1-pixel-thick force field, the pixel on the exterior side of the wall is empty (Visible == 00)!
  5. As soon as an empty exterior pixel is found, $6577 returns A = 0 with ($57, $58) set to that empty pixel's coordinates. The main loop calls JSR $646E to perform a scanline stack flood-fill from ($57, $58), then calls $6577 again until a full circuit of the Stix's boundary finds no remaining empty exterior pockets.

6. Clean TypeScript Implementation Reference

export const WIDTH = 160;
export const HEIGHT = 200;

export const enum ShadowState {
  EmptyOrFilled = 0, // Empty if visible == 0, Filled if visible != 0
  Stix = 1,          // Stix segment pixel
  PlayerTrail = 2,   // Incomplete player line
  Wall = 3,          // Completed wall / border
}

export interface Point {
  x: number;
  y: number;
}

export class StixEngine {
  visible = new Uint8Array(WIDTH * HEIGHT);
  shadow = new Uint8Array(WIDTH * HEIGHT);

  // $4B12..$4B15: Stix endpoints (X1, X2, Y1, Y2)
  coords = [120, 130, 150, 150]; // [X1, X2, Y1, Y2]
  readonly minBounds = [4, 4, 17, 17];
  readonly maxBounds = [155, 155, 195, 195];

  // $4B16 & $C000..$CFFF: 8-slot ring buffer of rasterized segments
  ringIndex = 0;
  trailHistory: Point[][] = Array.from({ length: 8 }, () => []);

  // $4B24, $4B27, $4B28: Mode 1 (Targeted Swoop) state
  swoopMode = false;
  swoopSpeed = 0;
  swoopIndex = 0;
  swoopPath1: Point[] = [];
  swoopPath2: Point[] = [];

  playerHit = false;
  frameCounter = 0;

  private idx(x: number, y: number): number {
    return y * WIDTH + x;
  }

  private randByte(): number {
    return (Math.random() * 256) | 0;
  }

  /** Bresenham line generator matching $6D8B */
  bresenhamLine(x0: number, y0: number, x1: number, y1: number): Point[] {
    const pts: Point[] = [];
    const dx = Math.abs(x1 - x0);
    const dy = Math.abs(y1 - y0);
    const sx = x0 < x1 ? 1 : -1;
    const sy = y0 < y1 ? 1 : -1;

    let x = x0;
    let y = y0;
    if (dx >= dy) {
      let err = (dx - (dy >> 1)) >> 1;
      for (let i = 0; i <= dx; i++) {
        pts.push({ x, y });
        err -= dy;
        if (err < 0) {
          err += dx;
          y += sy;
        }
        x += sx;
      }
    } else {
      let err = (dy - (dx >> 1)) >> 1;
      for (let i = 0; i <= dy; i++) {
        pts.push({ x, y });
        err -= dx;
        if (err < 0) {
          err += dy;
          x += sx;
        }
        y += sy;
      }
    }
    return pts;
  }

  /** Single Stix movement tick matching $6703 */
  stepStix(): void {
    this.frameCounter = (this.frameCounter + 1) & 0xff;

    if (this.swoopMode) {
      // $6804..$6853: Advance along precomputed converging paths
      for (let s = 0; s < this.swoopSpeed; s++) {
        this.swoopIndex++;
        const p1 = this.swoopPath1[this.swoopIndex];
        const p2 = this.swoopPath2[this.swoopIndex];
        if (!p1 || !p2) {
          this.swoopMode = false;
          this.stepStix();
          return;
        }
        const cell = this.idx(p1.x, p1.y);
        if (this.visible[cell] !== 0 && this.shadow[cell] !== ShadowState.Stix) {
          this.swoopMode = false;
          this.stepStix();
          return;
        }
      }
      if (this.swoopSpeed === 0) {
        this.swoopMode = false;
        this.stepStix();
        return;
      }
      const p1 = this.swoopPath1[this.swoopIndex];
      const p2 = this.swoopPath2[this.swoopIndex];
      this.coords[0] = p1.x;
      this.coords[1] = p2.x;
      this.coords[2] = p1.y;
      this.coords[3] = p2.y;
    } else {
      // $670D: 16/256 (6.25%) chance to initiate Mode 1 Swoop
      if (this.randByte() >= 0xf0) {
        const rx = this.randByte();
        const ry = this.randByte() ^ this.frameCounter;
        if (rx < 0x98 && ry < 0xb3) {
          const tx = rx + 4;
          const ty = ry + 17;
          this.swoopPath1 = this.bresenhamLine(tx, ty, this.coords[0], this.coords[2]).reverse();
          this.swoopPath2 = this.bresenhamLine(tx, ty, this.coords[1], this.coords[3]).reverse();
          this.swoopIndex = 0;
          this.swoopSpeed = this.randByte() & 0x06; // 0, 2, 4, or 6
          this.swoopMode = true;
          return;
        }
      }

      // $6781..$6801: Mode 0 — Independent Random Walk on Y2, Y1, X2, X1
      for (let c = 3; c >= 0; c--) {
        const r = this.randByte();
        const steps = (r & 0x07) + 1;
        const dir = (r & 0x80) === 0 ? 1 : -1;

        for (let s = 0; s < steps; s++) {
          this.coords[c] += dir;
          if (dir > 0 && this.coords[c] >= this.maxBounds[c]) {
            this.coords[c]--;
            break;
          }
          if (dir < 0 && this.coords[c] < this.minBounds[c]) {
            this.coords[c]++;
            break;
          }

          const ep = c & 1; // 0 for (X1,Y1), 1 for (X2,Y2)
          const ex = this.coords[ep];
          const ey = this.coords[ep + 2];
          const cell = this.idx(ex, ey);

          if (this.visible[cell] !== 0) {
            if (this.shadow[cell] === ShadowState.Stix) {
              continue;
            } else if (this.shadow[cell] === ShadowState.PlayerTrail) {
              this.playerHit = true;
              continue;
            } else {
              // Blocked by Wall or Filled region: undo step and stop this axis
              this.coords[c] -= dir;
              break;
            }
          }
        }
      }
    }

    this.rasterizeAndClipSegment();
  }

  /** $6862..$6927: Rasterize candidate segment, erase 8th-oldest trail, clip at walls & snap endpoints */
  private rasterizeAndClipSegment(): void {
    const candidate = this.bresenhamLine(
      this.coords[0],
      this.coords[2],
      this.coords[1],
      this.coords[3]
    );

    // $6928: Erase oldest segment in current ring slot if still marked as Stix
    for (const pt of this.trailHistory[this.ringIndex]) {
      const cell = this.idx(pt.x, pt.y);
      if (this.shadow[cell] === ShadowState.Stix) {
        this.visible[cell] = 0;
        this.shadow[cell] = ShadowState.EmptyOrFilled;
      }
    }

    // $688D..$68F5: Walk candidate line, stop on first wall/filled pixel
    const drawn: Point[] = [];
    for (const pt of candidate) {
      const cell = this.idx(pt.x, pt.y);
      if (this.visible[cell] === 0) {
        this.visible[cell] = 1;
        this.shadow[cell] = ShadowState.Stix;
        drawn.push(pt);
      } else if (this.shadow[cell] === ShadowState.Stix) {
        continue;
      } else if (this.shadow[cell] === ShadowState.PlayerTrail) {
        this.playerHit = true;
        continue;
      } else {
        // Hit wall or captured area: truncate segment immediately!
        break;
      }
    }

    // $68F7..$6914: Snap (X1,Y1) and (X2,Y2) to first and last drawn pixels
    if (drawn.length >= 2) {
      this.coords[0] = drawn[0].x;
      this.coords[2] = drawn[0].y;
      const last = drawn[drawn.length - 1];
      this.coords[1] = last.x;
      this.coords[3] = last.y;
    }

    this.trailHistory[this.ringIndex] = drawn;
    this.ringIndex = (this.ringIndex + 1) & 0x07;
  }
}
